# คู่มือเริ่มต้น scope (สำหรับคนที่ยังไม่มีอะไรเลย)

scope เป็นส่วนเสริม (plugin) ของ Claude Code ที่ช่วยลดจำนวน token ที่ Claude ต้องอ่านซ้ำทุกครั้งที่คุณส่งข้อความ ใช้โควตาช้าลง และใช้งานได้นานขึ้นก่อนจะชนลิมิต

คู่มือนี้พาทำตั้งแต่ยังไม่มีโปรแกรมอะไรเลย จนตั้งค่าเสร็จ ใช้เวลาราว 15 นาที

## 1. สิ่งที่ต้องมี

| สิ่งที่ต้องมี | จำเป็นไหม | หมายเหตุ |
|---|---|---|
| บัญชี Claude ที่ใช้ Claude Code ได้ (เช่น Pro หรือ Max) | จำเป็น | สมัครที่ [claude.ai](https://claude.ai) |
| แอป Claude บนคอม (desktop) หรือ Claude Code แบบ terminal | จำเป็นอย่างใดอย่างหนึ่ง | แนะนำแอป desktop เพราะใช้ฟีเจอร์ได้ครบ |
| Node.js เวอร์ชัน 20 ขึ้นไป | จำเป็น | scope เขียนด้วย JavaScript ต้องมี Node.js ไว้รัน |
| บัญชี TypeSafe และ API key | ไม่บังคับ | ใช้กับฟีเจอร์ JEV เท่านั้น ดูข้อ 6 |

## 2. ติดตั้ง Claude

**แบบแอป desktop (แนะนำ)**

1. ดาวน์โหลดจาก [claude.ai/download](https://claude.ai/download) เลือก Mac หรือ Windows
2. ติดตั้งแล้วเปิดแอป ล็อกอินด้วยบัญชี Claude
3. กดแท็บ **Code** ด้านบน แล้วเลือกโฟลเดอร์งานของคุณ

**แบบ terminal**

ทำตามหน้า [Claude Code quickstart](https://docs.claude.com/en/docs/claude-code/quickstart) แล้วพิมพ์ `claude` ในโฟลเดอร์งาน

## 3. ติดตั้ง Node.js

1. เข้า [nodejs.org](https://nodejs.org) ดาวน์โหลดรุ่น **LTS**
2. เปิดไฟล์ที่โหลดมาแล้วกด Next จนจบ
3. เช็กว่าติดตั้งแล้ว: เปิด Terminal (Mac) หรือ PowerShell (Windows) แล้วพิมพ์

   ```bash
   node -v
   ```

   ถ้าขึ้นเลขตั้งแต่ `v20` ขึ้นไป (เช่น `v22.11.0`) ถือว่าใช้ได้

4. **ปิดแอป Claude แล้วเปิดใหม่** เพื่อให้แอปเห็น Node.js ที่เพิ่งติดตั้ง

## 4. ติดตั้ง scope

ในแท็บ Code ของแอป หรือในหน้าต่าง `claude` ที่ terminal พิมพ์ทีละบรรทัด:

```
/plugin marketplace add Kreycin/scope
```

```
/plugin install scope@scope
```

หรือจะติดตั้งจาก terminal ก็ได้:

```bash
claude plugin marketplace add Kreycin/scope
```

```bash
claude plugin install scope@scope
```

จากนั้น **เริ่มเซสชันใหม่** (ในแอปกดสร้างเซสชันใหม่ ถ้าใช้ terminal ให้ปิดแล้วพิมพ์ `claude` ใหม่) scope จะเริ่มทำงานตั้งแต่เซสชันนี้ และวันละครั้ง Claude จะเตือนให้ตั้งค่าจนกว่าคุณจะตั้งค่าเสร็จ

## 5. ตั้งค่าฟีเจอร์

พิมพ์:

```
/scope:setup
```

Claude จะถามว่าอยากเปิดฟีเจอร์ไหน ให้ติ๊กเลือกได้เลย:

| ฟีเจอร์ | ค่าเริ่มต้น | ทำอะไร | ควรเปิดไหม |
|---|---|---|---|
| ปิด connector ที่ไม่ใช้ (`connectors`) | เปิด | connector ของ claude.ai (เช่น Gmail, Vercel) กิน token ทุกข้อความแม้ไม่ได้ใช้ scope จะปิดตัวที่งานไม่ใช้ แล้วเปิดให้เมื่อข้อความพูดถึงงานที่ต้องใช้ | เปิด |
| เตือนเซฟแล้ว clear (`handoff`) | เปิด | พอแชตยาวมาก (context เกิน 100k token) และงานจบขั้น เช่น commit แล้ว เทสผ่าน หรือคุณพิมพ์ "โอเค" Claude จะเซฟสถานะงานไว้ แล้วบอกให้พิมพ์ `/clear` เซสชันใหม่จะได้สถานะคืน ทำงานต่อได้เลย | เปิด |
| clear อัตโนมัติ (`autoClear`) | ปิด | ใช้ได้เฉพาะแอป desktop พอถึงจังหวะข้างบน Claude จะเซฟสถานะ export แชตเก็บไว้ใน `Downloads` แล้วล้างแชตให้เอง เซสชันใหม่เปิดมาพร้อมสรุปสั้นๆ ไฟล์ export ที่เกิน 5 อันล่าสุดจะถูกย้ายไปถังขยะ (ไม่ลบถาวร) | เปิดถ้าไม่อยากพิมพ์ `/clear` เอง |
| กันข้อความหลังพักนาน (`idleBlock`) | ปิด | ถ้าหายไปเกิน 60 นาทีแล้วแชตยังยาว ข้อความแรกที่ส่งจะแพงราว 2 เท่า (ระบบต้องโหลดแชตทั้งหมดใหม่) scope จะกันข้อความนั้นไว้หนึ่งครั้ง ให้คุณเลือกว่าจะ `/clear` ก่อน หรือส่งซ้ำเพื่อไปต่อ | เปิดถ้ามักพักกลางงาน |
| เตือน skill ใหญ่ (`bigSkill`) | เปิด | skill บางตัวยาวมาก (เกิน 20k token) พอโหลดเข้ามาแล้วจะติดอยู่ในแชตตลอด scope จะเตือนให้ `/clear` หลังงานนั้นเสร็จ | เปิด |

ถ้าคุณตั้ง JEV ไว้แล้ว (ข้อ 6) Claude จะถามเรื่อง JEV เพิ่มด้วย ค่าที่เลือกมีผลตั้งแต่ข้อความถัดไป อยากเปลี่ยนเมื่อไรก็พิมพ์ `/scope:setup` ใหม่ได้

## 6. JEV (ไม่บังคับ)

**JEV คืออะไร** เป็นโมเดลตัดสินใจแบบเร็วของบริษัท TypeSafe scope ใช้ถามคำถามเดียว คือ "งานจบขั้นแล้วหรือยัง" ในกรณีที่ไม่มีสัญญาณชัด (ไม่มี commit ไม่มีเทสผ่าน ไม่มีคำว่า "โอเค") ช่วยให้การเตือนเซฟแล้ว clear มาถูกจังหวะขึ้น

**ถ้าไม่ตั้ง** scope ยังทำงานได้ปกติ แค่จะดูเฉพาะสัญญาณชัดๆ และเตือนแน่นอนเมื่อแชตเกิน 300k token

**ค่าใช้จ่าย** TypeSafe คิดเงินตามการใช้งาน แต่ scope ถามแค่ตอนแชตยาวเกิน 100k และไม่มีสัญญาณชัดเท่านั้น จากการทดสอบ ถาม 125 ครั้งเสียไปราว $0.007 ดูราคาปัจจุบันได้ในหน้า console ของ TypeSafe

### ขั้นตอนตั้ง JEV

1. สมัครและล็อกอินที่ [console.typesafe.ai](https://console.typesafe.ai)
2. เข้าหน้า [API keys](https://console.typesafe.ai/keys) กดสร้าง key แล้วคัดลอกไว้
3. เก็บ key ไว้ในไฟล์ส่วนตัวที่ scope อ่านได้ เปิด Terminal แล้วพิมพ์ทีละบรรทัด (แทน `วาง-key-ตรงนี้` ด้วย key ของคุณ):

   ```bash
   mkdir -p ~/.config/typesafe
   ```

   ```bash
   echo 'TYPESAFE_API_KEY=วาง-key-ตรงนี้' > ~/.config/typesafe/env
   ```

   ```bash
   chmod 600 ~/.config/typesafe/env
   ```

   คำสั่งสุดท้ายทำให้ไฟล์อ่านได้เฉพาะบัญชีคุณ

   > ทำไมใช้ไฟล์แทนการตั้งตัวแปรใน `~/.zshrc` แอป desktop ที่เปิดจาก Dock มักไม่อ่าน `~/.zshrc` ไฟล์นี้ scope อ่านได้เสมอไม่ว่าเปิดแบบไหน ถ้าตั้งตัวแปร `TYPESAFE_API_KEY` ไว้ด้วย ตัวแปรจะถูกใช้ก่อน

4. พิมพ์ `/scope:setup` แล้วเลือกค่าของ JEV:
   - **auto** (ค่าเริ่มต้น): เปิดเองเมื่อเจอ key
   - **on**: เปิดเสมอ
   - **off**: ไม่ใช้ แม้จะมี key

**ข้อมูลที่ส่งออกไป** ตอนถาม JEV scope จะส่งข้อความล่าสุดของคุณ คำตอบล่าสุดของ Claude (อย่างละไม่เกิน 1,500 ตัวอักษร) และชื่อเครื่องมือที่ Claude เพิ่งใช้ ไปที่ `api.typesafe.ai` ถ้างานของคุณมีข้อมูลลับที่ห้ามส่งออกนอกบริษัท ให้ตั้ง JEV เป็น **off**

**ความเข้มงวด** ค่าเริ่มต้นคือ JEV ต้องมั่นใจอย่างน้อย 85% ว่างานจบขั้นแล้วถึงจะเตือน ถ้าอยากให้เตือนบ่อยขึ้น แก้ `~/.config/scope/config.json` เป็น:

```json
{ "handoff": { "jev": { "threshold": 0.75 } } }
```

(ถ้าไฟล์มีค่าอื่นอยู่แล้ว ให้เพิ่ม `handoff` เข้าไปในวงเล็บเดิม อย่าสร้างวงเล็บชุดใหม่)

## 7. ใช้งานจริงเป็นอย่างไร

ส่วนใหญ่ไม่ต้องทำอะไรเลย scope ทำงานเบื้องหลัง สิ่งที่คุณจะเห็น:

- **พูดถึงงานที่ต้องใช้ connector** เช่น "deploy ขึ้น vercel" Claude จะเปิด connector ให้ แล้วบอกว่าพร้อมใช้ในข้อความถัดไป ให้ส่งคำสั่งอีกครั้ง
- **แชตยาวและงานจบขั้น** Claude จะเซฟสถานะงาน แล้วบอกให้พิมพ์ `/clear` (หรือ clear ให้เองถ้าเปิด `autoClear`) เซสชันใหม่ Claude จะรู้ว่าทำอะไรค้างไว้
- **กลับมาหลังพักนาน** (ถ้าเปิด `idleBlock`) ข้อความแรกจะถูกกันไว้พร้อมคำอธิบาย ส่งซ้ำเพื่อไปต่อ หรือพิมพ์ `/clear` ก่อน

**สถานะงานเก็บที่ไหน** ค่าเริ่มต้นเก็บเป็นไฟล์ส่วนตัวใน `~/.local/share/scope/handoff/` และจะคืนให้เฉพาะเมื่อ clear แล้วเปิดในโฟลเดอร์เดิมภายใน 24 ชั่วโมง ถ้าอยากให้เก็บเป็น `STATUS.md` ในโปรเจกต์ของคุณเอง ดูหัวข้อ "Where state goes" ใน [README](../README.md#where-state-goes)

## 8. อัปเดต ปิด และถอนการติดตั้ง

**อัปเดตเป็นเวอร์ชันใหม่**

```bash
claude plugin marketplace update scope
```

```bash
claude plugin update scope@scope
```

แล้วเริ่มเซสชันใหม่

**ปิดชั่วคราวทุกฟีเจอร์** ตั้งตัวแปร `SCOPE_OFF=1` หรือปิดทีละตัวด้วย `/scope:setup`

**ถอนการติดตั้ง**

```
/plugin uninstall scope@scope
```

ค่าที่ตั้งไว้ยังอยู่ใน `~/.config/scope/` และ log กับสถานะอยู่ใน `~/.local/share/scope/` ถ้าอยากล้างหมดให้ลบสองโฟลเดอร์นี้ด้วย ส่วน key ของ JEV อยู่ใน `~/.config/typesafe/env`

## 9. แก้ปัญหา

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| พิมพ์ `/scope:setup` แล้วไม่มีคำสั่งนี้ | ยังไม่ได้เริ่มเซสชันใหม่หลังติดตั้ง | เริ่มเซสชันใหม่ หรือพิมพ์ `/plugin` ดูว่ามี `scope` ในรายการไหม |
| ไม่มีอะไรเกิดขึ้นเลย ไม่มีการเตือน | แอปหา Node.js ไม่เจอ | เช็ก `node -v` ใน Terminal แล้วปิดเปิดแอป Claude ใหม่ |
| ไม่มีอะไรเกิดขึ้นเลย และ Node.js ปกติ | ไฟล์ `~/.config/scope/config.json` เขียนผิดรูปแบบ (scope จะเงียบแทนการเดา) | แก้ไฟล์ให้เป็น JSON ที่ถูกต้อง หรือลบไฟล์แล้วรัน `/scope:setup` ใหม่ |
| JEV ไม่ทำงาน | ไม่เจอ key หรือ key ผิด | เช็กไฟล์ `~/.config/typesafe/env` ว่ามีบรรทัด `TYPESAFE_API_KEY=...` และ key ยังใช้ได้ในหน้า console |
| clear อัตโนมัติไม่ทำงาน | ใช้ Claude Code ใน terminal หรือเปิด Remote Control อยู่ | ฟีเจอร์นี้ใช้ได้เฉพาะแอป desktop กรณีอื่น Claude จะบอกให้พิมพ์ `/clear` เอง |
| อยากดูว่า scope ทำอะไรไปบ้าง | | ดู log ที่ `~/.local/share/scope/log.jsonl` |

ติดปัญหาอื่น แจ้งได้ที่ [GitHub Issues](https://github.com/Kreycin/scope/issues)
